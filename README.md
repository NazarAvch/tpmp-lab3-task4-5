# Лабораторная работа 3 — SQLite

## Ветки репозитория

- **main** — основная ветка с финальной версией проекта
- **examples** — примеры работы с SQLite на C (Задание 4)
- **dev** — консольное приложение "Человек" (Задание 5)

## Структура проекта

- `examples/` — 6 примеров использования SQLite C API с файлом EXAMPLES.md
- `project5/` — консольное приложение с меню для работы с БД
  - `src/` — исходный код (main.c, database.c, database.h)
  - `bin/` — исполняемый файл
  - `data/` — база данных people.db
  - `Makefile` — сборка утилитой make
